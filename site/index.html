moon_vegalite

用 MoonBit 写的 Vega-Lite 渲染器，编译成 JavaScript 后直接运行在你的浏览器里。 左边修改 Vega-Lite JSON，中间是本库实时渲染的 SVG，右边是官方 vega-embed 的渲染结果。

  • 本库是子集渲染器：遇到不支持的特性会报错，并给出出错位置的 JSON 路径（见「Not supported」里的示例），而不是画成别的样子。官方一侧仍会尽力渲染，方便对照。
    • 
    
  • 官方一侧关闭了浏览器的 canvas 文字测量（vega.textMetrics.canvas(false)），使用与测试基准相同的估算，两边的 SVG 才能逐字比较；比较时忽略无障碍属性。
    • 
    
  • 带时间轴的图：本库按 UTC 处理时间，官方在浏览器里按本地时区，时区不是 UTC 时两边可能不同。
    • 
    
  • 手绘风格：矩形、线、路径和符号交给 moon_rough 画，文字不变；同样的规格和 seed 得到逐字节相同的 SVG（为了体积，坐标只保留两位小数）。官方 vega-embed 只画普通版，所以手绘版不参与「是否相同」的比较；它与官方 rough.js 的一致性在测试里逐字节验证。
    • 
    
  • 官方一侧的 vega、vega-lite、vega-embed 从 jsDelivr 加载，需要联网。
